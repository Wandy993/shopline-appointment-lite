# Appointment Lite v0.6.8 — Booking Record Action Menu

This release simplifies the booking record table for merchant operations.

- Five-column booking hierarchy: customer/service, booking details, payment, appointment, actions.
- Date/time, staff, location, and timezone are grouped in one booking-details cell.
- Appointment activity remains directly visible for every record.
- Secondary actions move into an Appointment Lite custom action menu.
- SHOPLINE order access, editing, completion, no-show, cancellation, and record deletion stay available without widening the table.
- Destructive deletion retains the existing second-confirmation flow.
